# 1919 日食觀測：歷史背景、創作邊界與來源

> 此文件是**創作研究的起點**，不是經審定的完整史學定論。所有影響真實人物評價／科學結論的劇情，在定稿前必須核對相應史料。不要把後世對相對論的理解寫成 1919 年人物當下的知識。

## 可用於故事的歷史錨點

- **1919-05-29**：兩支英國組織的觀測隊分別前往**普林西比島（Príncipe）**與**巴西 Sobral**，試圖在日全食時拍攝太陽附近的背景星，測量其視位置偏折，藉以比較引力理論的不同預測。
- **Príncipe**：Arthur Stanley Eddington 與 Edwin Cottingham 在雲層干擾下進行觀測。相片有的能見到星點，但資料品質不一；研究綜述指出只有**兩張**照片最終可用於關鍵分析（不要混淆「拍到的照片數」與「可信用於測量的照片數」）。
- **Sobral**：另有 Frank Watson Dyson 組織的觀測工作，由 Andrew Crommelin、Charles Davidson 等參與；那裡的不同望遠鏡結果在最後比較中也很重要。**不能把整個 1919 驗證故事寫成普林西比單一底片／單一英雄的成果**。
- 當時的原始簡短消息：1919-06-05《Nature》提到來自 Príncipe 的「Through cloud, hopeful」，呈現的是**謹慎期待**，不是當場確定取得終極證明。
- **時間／沖洗與判讀**：日食時拍攝，後續經顯影、比較、測量與分析才能形成結論。研究資料指出 Eddington 在島上已能顯影與初步測量部分照片；進一步完整分析在返國後持續。**舊企劃要求「數日後才沖洗」過度固定，不應當成史實。** 實際時間與設備操作流程需查遠征紀錄後再寫入固定台詞。
- 1919 年的分析引起廣泛關注，但**單次遠征並非「所有疑點從此消失」**；玩家應能在證據品質、誤差和當時可得資訊之下做有限度的判斷。

## 適合改編成玩法，但須標明虛構

| 素材 | 目前分類 | 改編提醒 |
|---|---|---|
| 1919 日食、兩地觀測、雲層干擾、拍照與星點測量 | 史實背景 | 詳情以來源查核 |
| 玩家作為年輕助手／研究生 | FICTION | 不取代 Eddington、Cottingham、Dyson 或其他真實觀測者的貢獻 |
| 儀器固定處鬆動、底片批次品質異常、限時維修抉擇 | FICTION / 可能的戲劇重建 | 目前**沒有**證據認定實際發生，不能把它說成具名歷史事件 |
| 教授與玩家發生激烈爭執 | FICTION | 若對象是真實人物，需避免捏造惡意、舞弊、故意刪除不利資料 |
| 玩家在重疊星點影像後提出「證據尚不足」 | 遊戲化推理 | 數值／影像如為示意資料，必須標示；不可說是未經核對的真實底片 |
| 神祕時空 Hub、記號和物件 | FICTION | 可作長期主線，但不可成為物理理論的證據 |

重要戲劇倫理：**不依據未經核實的流行傳說指控 Eddington 篡改或挑選資料以欺騙公眾**。可討論觀測誤差、照片取捨、科學爭議及歷史上複雜的人性，但須公允對待當時的資料和人物。

## 可以發展的核心互動（非硬性 GDD）

玩家在 **Godot 3D** 場景中移動、觀察、和人物交談，親自執行一個「準備／檢查／觀測」操作；操作引起可觀察的品質或記錄差別。隨後檢查照片與筆記，提出**有理由、承認不確定性**的判斷，觸發 NPC 或故事回應。

早期提案曾寫「Hub 一間房一扇門 → 最後 20 分鐘 → 拍攝 → 數日後的底片比對 → 回 Hub」。其中可保留情緒與互動靈感，但**Hub 與精確時間結構不是新 MVP 必做要求**。先做真正好玩的 3D 單人切片。

## 開發前優先補查

1. Príncipe 真正的觀測位置、外觀、儀器、衣著與天氣，以及實際操作可行性（避免 3D 資產假冒史實）。
2. 觀測片與比對片的來源、時序、數據與其不確定度。
3. 角色台詞所涉及的真實人物態度、彼此往來、戰後政治與文化脈絡。
4. 圖像、文字、錄音、3D 素材各自的授權；**館藏網站上看得到不等於可直接商用遊戲素材**。
