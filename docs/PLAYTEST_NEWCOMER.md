# 新手盲玩測試：給主持人的一頁說明

**目的：** 找一位**沒讀過企劃、沒有物理背景**的人，第一次玩《雲層之後》。看他們卡在哪裡、在乎什麼、記得什麼。
自動化測試只能證明「走得通」，不能證明「好玩、看得懂、會在乎」。這一頁就是為了補上這一點。

## 準備（5 分鐘）
1. 用最新的 `main` 匯出 macOS 版，或用 Godot 4.7.2 直接執行：
   - 匯出：`godot --headless --path . --export-release "macOS" build/Eddington1919-macOS.zip`
   - 直接執行：`godot --path .`
2. 讓試玩者戴耳機或開聲音，用滑鼠和鍵盤玩。全螢幕或 1600×900。
3. 準備計時器，再準備紙筆或錄影（螢幕錄影要先徵得同意）。

## 主持規則（最重要）
- **開始前只說一句：**「這是一款歷史冒險遊戲的早期版本。請你像在家裡一樣玩，邊玩邊說出你在想什麼。我不會幫忙，除非你卡住超過兩分鐘。」
- **不要解釋**遊戲在講什麼、該按什麼、相對論是什麼。
- 卡住超過 2 分鐘，只能問：「你現在想做什麼？」不要直接給答案。給了提示的話，請記下時間和內容。
- 從標題畫面的「序章　劍橋，1917」開始。序章約 12–18 分鐘，之後會接到 1919 年的日食（約 6–10 分鐘）。時間不夠的話，玩完序章就可以停。

|---|---|---|---|
| | | | |

特別留意這幾個時刻：
- 第一次打開看片台，看到星點對不上時，他們怎麼反應？
- 有沒有自己發現抄錄圖角落的「14」是反的？花了多久？
- 寫報告時，有沒有猶豫要不要選「抄錄的人草率，或是憑空編造」？
- 規劃日食觀測時，有沒有讀角色的反應？還是一路點過去？
- 有沒有提到 Kit 或 Ashby 先生的名字？語氣如何？

## 玩完後的問題（照順序問，不要先給選項）
1. 用你自己的話說：序章裡你在查什麼？最後發現是怎麼回事？
2. 那一個沒對上的點，你怎麼處理？為什麼？
3. 如果要在日食時檢查「星星真的被推開了」，需要準備什麼，才不會被騙？（說不出來也沒關係，請照實記下。）
4. 有沒有哪個人物，你想知道那個人後來怎麼了？是誰？為什麼？
5. 哪一段最無聊、最搞不懂，或最想跳過？
6. 1919 年的日食：你看得出雲在變薄嗎？什麼時候按「開始」和「停」？
7. 0 到 10 分，你會想把這個遊戲推薦給朋友嗎？為什麼不是更低，也不是更高？
8. 現在還記得的一句台詞或一個畫面？

## 回報
把觀察表、八題的回答（盡量用原話）、總時長、提示次數，貼到 [Issue #1](https://github.com/nurockplayer/eddington-1919/issues/1)，並註明試玩者的背景（例如「大學生、文科、沒玩過類似遊戲」，不需要姓名）。
**一位真人的回答，比一百次自動化測試更有用。**
